# MTPV/MTEG 数据快照

公开仓库不包含 `research_46_20261002.json` 真实研究数据。以下说明专用入口的数据格式；请导入自己的表格，或在本机使用已获授权的私有快照。

在通用界面点击“MTPV/MTEG 物理耦合”，再点击“导入表格 / DAT”并确认列映射和单位。“载入论文 46 组数据”仅在本机另有私有快照时可用。输入表及相关派生量用于演示该领域工作流，不能代替原始网格、求解设置和独立物理验证材料。

| 字段 | 含义与单位 |
| :--- | :--- |
| `case`, `physical_case`, `batch` | 工况与批次标记 |
| `phi` | 当量比 |
| `L_mm` | 翅片长度，mm |
| `qm_1e5_kg_s` | 混合物质量流量，数值乘以 `10^-5 kg/s` |
| `dp_Pa` | 压降，Pa |
| `P_MTPV_W`, `P_MTEG_W` | 两级电功率，W |
| `P_total_W` | 两级总电功率，W；不扣除泵功 |
| `eta_gross_pct` | 燃料能量效率，%；不是火用效率 |
| `Y_H2_in` | 入口氢气质量分数 |
| `Q_rad_W`（可选） | 后处理辐射功率，W |
| `source_*`（可选） | 来源文件标记 |

真实研究记录、原始 `.cas.h5`、`.dat.h5`、Mechanical 结果和工作簿均未发布。私有 JSON 文件已加入忽略列表，防止误提交；三个通用演示项目只使用合成数据。

专用入口的响应留出检查与通用独立留出有所区别，详见 [使用指南](../docs/user-guide.zh-CN.md)。

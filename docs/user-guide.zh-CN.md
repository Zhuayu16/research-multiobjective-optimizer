# 研究多目标优化器：中文使用指南

版本 0.2.0。桌面研究软件：导入变量与响应表，建立代理模型，在工程约束内进行多目标搜索，并导出可追溯的结果。保留 MTPV/MTEG 物理耦合入口。

## 通用项目使用方法

1. 双击 `run_gui.bat`，进入通用研究项目界面。
2. 导入 Excel、CSV、TSV 或逐行记录 JSON。多工作表 Excel 可选择数据表。自动初选数值列后，务必确认变量、响应和目标方向。
3. 在“变量”页添加或删除行，选择数据列、单位、连续/整数/数值集合类型及边界。数值集合在“允许值”中用逗号分隔，例如 `2,4,6`。固定参数不要作为优化变量。
4. 在“目标/响应”页选择每个目标最小化或最大化，设置权重。只作限制的指标选择“仅用于约束”，会建立代理模型，但不参加 Pareto 目标或权重排序。支持一个或多个目标。
5. 在“约束”页填写响应/变量限值或关系，例如 `Tmax_K <= 315`、`abs(x-y) <= 0.2`。表达式支持列名、`col("带空格的列名")`、加减乘除、括号、`abs()`；关系与限值在独立列填写。`==` 应设置合理容差。尺度用于归一化违反量，必须为正数。
6. 在“数据与验证”页选择随机、分组或时间验证，以及重复测量处理。独立留出列/值可留空。例如选择 `batch` 与 `test`，整个批次的响应就不会参与选型、拟合或搜索域建立。
7. 在“运行与设计”页选择模型、种子、迭代和排序方式，点击“开始优化”。查看验证摘要、预测 Pareto、输入表 Pareto、工程约束诊断及独立留出结果。
8. “保存项目”保存原始数据和当前配置为 `.optproj`；“打开项目”完整恢复，可重新运行。“导出本次结果与图表”采用本次计算的配置快照，同时生成 Excel、参数 JSON、项目文件及 SVG/PDF/TIFF/PNG 图表。

单位字段用于显示和记录，不自动转换数值。变量边界不得超过训练样本范围。允许零值、负值响应；接近零时相对误差不计算，使用 RMSE/MAE/NRMSE。至少需要 10 个不同训练设计，每个连续变量至少 3 个水平，整数/集合变量至少 2 个水平；优化目标至少 3 个不同响应值。

## 领域模板与验证设置

内置电池液冷、换热器、结构设计和 MTPV/MTEG 直接响应模板。模板提供初始列名、单位、方向和约束，实际研究必须按数据定义调整。“载入合成示例”提供前三个领域的确定性函数数据，界面和导出均标明来源；这些数据只验证软件功能，不是物理试验或 CFD 结果。

| 功能 | 行为 |
|---|---|
| 任意目标方向 | 每列独立 min/max；目标数量不固定为三 |
| 工程约束 | NSGA-II 使用可行方案优先；不可行方案按归一化总违反量排序；无可行结果时报错 |
| 搜索域 | 训练范围边界框或样本凸包；凸包超过六维时提示使用边界框加覆盖限制；支持一维凸包 |
| 样本覆盖 | 可限制归一化最近样本欧氏距离，并导出距离；此距离不代表预测置信区间 |
| 重复测量 | 冲突报错/保留/按设计取均值；保留时随机验证自动按设计分组；均值处理保留重复次数 |
| 分组验证 | 指定组不会同时出现在训练与验证；重复设计跨不同组时提示整理 |
| 时间验证 | 按数字/日期排序，等时间块不拆开，前向验证；初始块不计入验证指标 |
| 独立留出 | 留出响应不参加选型或拟合；域外检验明确标记；相同设计的留出提示属于响应复验 |
| 偏好决策 | 默认 IDEAL，训练集固定尺度，超越理想点的改进记为零损失；另有 TOPSIS/ARAS |
| 试验设计 | 导出 30 行 LHS 与 3 个保留的中心重复，适配整数与数值集合；不保证未知响应约束可行 |
| 结果区分 | 代理模型预测与输入表实测/计算结果分开；导出保留清理行号、验证折、配置和数据校验值 |

Auto 对每个响应比较现有模型并选择 CV NRMSE 最小者。模型选择和 CV 误差展示共用折，未实现嵌套验证；独立留出指标用于检验选型后的模型。当前版本面向数值表格研究：无序类别、预测置信区间、自动追加仿真和大规模多目标专用算法仍需扩展。

## 安装与移植

启动脚本自动使用项目 `.venv`、可用的 Conda base 或系统 Python，不绑定盘符。可通过环境变量 `RESEARCH_OPTIMIZER_PYTHON` 指定解释器。项目目录可以移动，但 Python 环境需要安装依赖。

```powershell
python -m pip install -r requirements.txt
python app.py
```

也可安装为软件包：

```powershell
python -m pip install .
research-optimizer
```

建议 Python 3.10 或更高版本。Windows Qt 图形界面和当前 Anaconda 环境已测试；其他系统尚未实测。项目与运行参数可以恢复并重新计算，不保存可执行模型文件。

## 专用入口与私有研究数据

公开仓库不包含 46 组真实研究数据。专用界面支持导入自己的 Excel/CSV 等表格；下述一键载入说明仅适用于本机另有已获授权的数据快照。

通用界面点击“MTPV/MTEG 物理耦合”，进入保留的专用界面。以下说明仅针对这个入口。

点击“载入论文 46 组数据”可载入本机私有后处理数据快照，并设置 `N=6`、H2/air 耦合模式、种群 90、迭代 65、两次独立运行、种子 20260929 和 IDEAL 决策。46 组包含 25 组长度/当量比算例、17 组联合变化算例和 4 组候选复算。

`data/research_46_20261002.json` 为独立的数据快照。导入自己的 Excel/CSV/TSV/JSON 后，在界面确认列映射、质量流量单位和边界。

## 两种模式

### H2/air 两级耦合

决策变量包括当量比 `phi`、混合物入口质量流量和翅片长度；可额外启用整数翅片数。输入响应为压降、MTPV 电功率和 MTEG 电功率，三者必须使用 Pa/W。

- 分别拟合 `dp_Pa`、`P_MTPV_W`、`P_MTEG_W`。
- `P_total_W = P_MTPV_W + P_MTEG_W`，为两级总电功率，不扣除泵功。
- `Y_H2 = phi / (34.32 + phi)`。
- 燃料输入 `Q_fuel = m_dot_mix * Y_H2 * LHV`。
- `eta_gross_pct = 100 * P_total_W / Q_fuel`，为燃料能量效率，不是火用效率。

流量单位明确选择 `数值 × 10^-5 kg/s` 或 `数值 kg/s`；H2 低位热值默认 119.96 MJ/kg，化学计量空燃质量比默认 34.32。可映射入口 H2 质量分数用于一致性核对。质量流量不能填写成 H2 单独质量流量。

本模式的 Auto 比较二次响应面与 ARD Matérn-5/2 高斯过程：输入标准化在各训练折内完成，GP 使用 `alpha=1e-5`、输出归一化、一次核参数重启。五折随机划分用于两种模型共同比较；根据压降和总功率的平均 MAPE 选择整套模型，不重复计入由功率派生的效率误差。同一划分也用于所展示的误差报告。

“响应留出”勾选后，冻结不含 `3.3_confirmation` 批次的响应训练集，预测四组实际执行参数。最终搜索模型仍使用全部 46 组。此检验是响应留出检查；模型类型来自全样本 CV 选型，不称为独立外部验证。

### 专用界面的直接响应模式

保留压降、功率、效率分别拟合的原有流程，支持 Linear、RSM、MLP、GP、SVR、随机森林、ExtraTrees 和梯度提升。Auto 对每个响应分别选择交叉验证 NRMSE 最低的模型。净功率/净效率数据应使用此模式，不能在两级总功率模式中混用。

## 搜索与决策

- 默认限制在联合输入样本的凸包内，同时满足用户边界。越界预测返回无效值，不把输入悄悄截断到边界。秩不足的输入会拒绝建立凸包。
- NSGA-II 使用 SBX（概率 0.9、eta 15）和多项式变异（每变量概率 1/d、eta 20）；独立种子相隔 7919。
- 可启用差分进化核对三目标端点及当前权重的平衡候选。端点种群倍率 12、90 代；平衡搜索倍率 16、130 代。关闭额外局部抛光，导出搜索终止状态和实际参数。
- IDEAL 采用固定尺度：压降成本 `(dp-low)/(high-low)`，功率、效率成本 `(high-value)/(high-low)`，距离 `sqrt(sum(w * cost^2))`，越小越优；表中的效用为 `1/(1+distance)`。
- 不指定尺度时，在搜索前由整张输入表确定一次最小/最大值；指定尺度时使用界面设置。所有种子和偏好对比共享同一尺度，导出时保存。
- 保留 TOPSIS/ARAS。它们按各候选集合归一化，与固定尺度 IDEAL 不同。“偏好对比”页统一使用 IDEAL，展示等权、压降优先、功率优先、效率优先和当前权重。
- “已计算方案”只排序输入表的非支配方案；“Pareto 解”只显示代理模型候选，两类结果不混为已经实现的性能。

论文固定尺度下，等权推荐 OPT01，压降优先推荐 OPT04，功率优先推荐 T04，效率优先推荐 OPT01。

## 导入与导出

支持多工作表 Excel、CSV、TSV、逐工况记录列表 JSON、文本 DAT；保留 CFD-Post 曲线 DAT 批量导入。Fluent `.dat.h5` 不是表格，仍需配套 `.cas.h5` 和物理报告提取。

重复输入但响应不一致的工况会被拒绝合并。整数变量必须为整数。无穷值、空值和非数值行会被剔除并记录。

运行在后台线程，界面保持响应；可取消。重新载入数据清空旧结果。导出使用计算启动时的参数快照，不使用运行后修改的界面设置。

输出工作簿包括：模型预测 Pareto、已计算 Pareto、固定尺度偏好对比、独立运行比较、端点核对、CV 指标与逐工况预测、响应留出、源数据和运行设置。同时输出参数 JSON（含数据校验值、软件版本、模型与遗传算子参数）。输入原有总功率和效率以 `_input` 后缀保留。

出版图保留 SVG/PDF、600 dpi TIFF 和 300 dpi PNG；模型候选和已计算方案采用不同标记，不连接离散 Pareto 点。

# 软件架构与数据流

通用流程以 `Problem` 描述研究对象，将数值计算与 Qt 界面分开。MTPV/MTEG 的燃料与功率耦合保留在独立领域模块中。

| 模块 | 职责 |
| :--- | :--- |
| `problem.py` | 变量、目标、约束及验证设置；受限算术表达式；项目读写 |
| `general.py` | 清理与重复设计处理；留出与 CV 划分；覆盖检查；通用模型与搜索编排 |
| `core.py` | 代理模型构建、交叉验证、目标方向、偏好评分 |
| `nsga2.py` | 非支配排序、拥挤距离、SBX 交叉、多项式变异、约束优先搜索 |
| `domain.py` | 样本凸包与输入范围检查 |
| `coupled.py` | MTPV/MTEG 两级响应与 H2/air 物理派生量 |
| `workflow.py` | 兼容工作流、结果结构、工作簿与参数导出 |
| `general_ui.py` | 通用 Qt 界面、后台任务、项目恢复与导出入口 |
| `general_figures.py` | 动态目标权衡图、平行坐标、验证图与出版格式输出 |
| `presets.py` / `doe.py` | 领域初始配置、合成演示数据与试验设计 |
| `dat_parser.py` | 文本 DAT 与曲线数据解析 |
| `launcher.py` / `app.py` | 启动通用界面；保留领域界面与兼容入口 |

## 通用计算流程

1. 验证 `Problem` 中的数据列、变量类型、目标及约束表达式。
2. 清理无效行，记录原始行号；按独立留出标记分开训练/检验数据，然后处理各自重复设计。
3. 只在训练数据上建立随机、分组或时间前向划分，比较模型并拟合选定模型。
4. 只以训练样本建立搜索域与可选覆盖限制，评估变量/响应约束并进行多次 NSGA-II 搜索。
5. 合并可行候选，计算非支配方案与偏好排序；另行计算输入表可行 Pareto。
6. 评估独立留出响应并标记域外情况；输出模型指标、验证逐行预测、数据审计、约束诊断和运行设置。

## 项目和导出

`.optproj` 是含数据与问题配置的 JSON 项目文件。打开后重建配置和表格，运行时重新拟合模型。导出使用后台计算开始时的配置快照，避免运行结束后修改控件改变已完成结果的描述。

结果中的输入表方案来源于实际输入记录；预测方案来源于代理模型。两者分别显示和导出，不能将预测值当成已验证性能。

## 扩展新的研究对象

大多数数值表格问题直接在界面配置即可。固定派生物理量、多阶段耦合等需要新增代码的情况，应参考 `coupled.py` 的职责分离，避免向通用输入清理或评分逻辑中加入具体领域常数。

当前未实现类别编码、嵌套交叉验证、预测置信区间、自动仿真执行或大规模多目标专用算法。相关扩展需要独立验证其数据划分、搜索域和预测证据。
